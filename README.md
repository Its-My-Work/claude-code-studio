# Claude Code Studio

**Full-featured web workspace for Claude Code** — чат, Kanban, многоагентная система, MCP, навыки и управление проектами.

## 🚀 О проекте

Claude Code Studio — это веб-приложение, предоставляющее удобный интерфейс для работы с Claude AI (Anthropic). Приложение объединяет несколько мощных функций:

- **AI Чат** — интерактивный диалог с Claude Code в реальном времени
- **Kanban** — управление задачами на доске с автоматическим выполнением
- **Многоагентная система** — распределение задач между специализированными агентами
- **MCP (Model Context Protocol)** — расширение возможностей через внешние серверы
- **Skills/Навыки** — специализированные роли для решения конкретных задач
- **Telegram Bot** — удалённое управление через мессенджер

### Компоненты системы

**Сервер (`server.js`)**
- Express.js веб-сервер с WebSocket поддержкой
- REST API для управления сессиями, задачами и настройками
- Система аутентификации (логин/пароль, Telegram-аутентификация)
- Очередь задач с автоматическим выполнением
- Архивирование статистики при удалении сессий

**Бэкенды**
- `KiloBackend` — интеграция с Kilo CLI для доступа к Claude
- Поддержка различных моделей (haiku, sonnet, opus)
- Многоагентный режим с распределением задач

**MCP Серверы (внутренние)**
- `mcp-ask-user` — запросы подтверждения у пользователя
- `mcp-notify` — уведомления о событиях
- `mcp-task-manager` — создание и управление задачами
- `mcp-set-ui-state` — управление состоянием интерфейса
- `mcp-user-interrupt` — прерывание выполнения задач

**Telegram Bot**
- Удалённое взаимодействие с Claude через мессенджер
- Многоязычная поддержка (ru, en, uk)
- Индивидуальные чаты для разных пользователей

## 📦 Установка и запуск

### Требования
- Node.js >= 18
- Kilo CLI (установленный глобально)

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/Lexus2016/claude-code-studio.git
cd claude-code-studio

# Установка зависимостей
npm install

# Создание файла окружения
cp .env.example .env
```

### Конфигурация (.env)

```bash
# Порт сервера
PORT=3000

# URL Kilo сервера
KILO_SERVER_URL=http://127.0.0.1:4098

# Настройки прокси (для rate limiting)
TRUST_PROXY=true

# Таймауты
KILO_REQUEST_TIMEOUT=30000
SESSION_TTL_DAYS=30
CLEANUP_INTERVAL_HOURS=24
MAX_TASK_WORKERS=5
```

### Запуск

```bash
# Стандартный запуск
npm start

# Режим разработки (с авто-перезагрузкой)
npm run dev
```

Откройте браузер и перейдите по адресу `http://localhost:3000`

## 🎯 Как пользоваться

### 1. Авторизация

При первом запуске система потребует создать учетную запись:
- Введите имя пользователя и пароль
- Данные сохраняются в `.env` файл и базе данных

### 2. AI Чат

**Создание сессии:**
1. Нажмите кнопку "Новая сессия" в боковой панели
2. Выберите рабочую директорию (workspace)
3. Начните писать запрос — Claude ответит в реальном времени

**Настройки сессии:**
- **Model** — выбор модели (haiku/sonnet/opus)
- **Mode** — режим работы (auto, plan, task)
- **Agent Mode** — single/multi для многоагентного выполнения

### 3. Kanban (Управление задачами)

**Создание задачи:**
1. Перейдите на вкладку Kanban
2. Нажмите "+" в колонке Backlog
3. Заполните название, описание и заметки
4. Перетащите задачу в колонку Todo для запуска

**Workflow:**
```
Backlog → Todo → In Progress → Done
                ↓
            Cancelled (при ошибке)
```

**Автоматическое выполнение:**
- Система автоматически обрабатывает задачи из колонки Todo
- Максимум 5 одновременно выполняемых задач (настраивается)
- Автоматический retry при ошибках

### 4. Многоагентный режим

Позволяет распределять сложные задачи между специализированными агентами:

1. Включите режим Multi-Agent в настройках
2. Claude автоматически разобьёт задачу на подзадачи
3. Каждый агент получит специализированную роль (architect, coder, tester и др.)
4. Прогресс виден на карточке команды агентов

### 5. MCP Серверы

**Подключение внешних MCP серверов:**
1. Откройте Настройки → MCP Серверы
2. Добавьте сервер (stdio или HTTP)
3. Укажите команду и переменные окружения
4. Активируйте для текущей сессии

**Пример подключения сервера файловой системы:**
```json
{
  "name": "filesystem",
  "type": "stdio",
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
}
```

### 6. Навыки (Skills)

Система автоматически выбирает подходящих специалистов на основе задачи:

- **API-Designer** — проектирование REST API
- **Backend-Engineer** — серверная архитектура
- **Frontend-Engineer** — React/Vue приложения
- **Security-Expert** — анализ безопасности
- **DevOps-Engineer** — CI/CD и деплой

### 7. Telegram Bot

Настройка удалённого доступа:

```bash
# В .env добавьте токен бота
TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
```

Функции:
- Отправка сообщений через `/send <текст>`
- Получение ответа в том же чате
- Индивидуальные сессии для каждого пользователя

## 🛠️ API Endpoints

### Сессии
```
GET    /api/sessions           # Список сессий
POST   /api/sessions           # Создать сессию
GET    /api/sessions/:id       # Получить сессию
PUT    /api/sessions/:id       # Обновить сессию
DELETE /api/sessions/:id       # Удалить сессию
```

### Сообщения
```
GET    /api/sessions/:id/messages    # Получить сообщения
POST   /api/sessions/:id/messages    # Отправить сообщение
```

### Задачи
```
GET    /api/tasks              # Список задач
POST   /api/tasks              # Создать задачу
PUT    /api/tasks/:id          # Обновить задачу
DELETE /api/tasks/:id          # Удалить задачу
```

### WebSocket
```
ws://localhost:3000/ws         # Реальное время для чата
```

```json
  }
}
```
