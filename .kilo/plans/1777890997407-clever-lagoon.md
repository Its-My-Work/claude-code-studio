# План реализации режима отображения ответов и размышлений (ИСПРАВЛЕННЫЙ)

## Цель
Добавить настройку KILO_STREAM_MODE в переменных окружения для управления режимом отображения ответов и размышлений AI агента: native (по умолчанию, посимвольный стриминг) или buffered (накопление и отображение целиком).

## Текущая ситуация
- Серверный код в `server.js` обрабатывает события `onText` и `onReasoning` для стриминга
- Клиентский код в `public/index.html` обрабатывает WebSocket сообщения типа `ai_chunk` с `kind: 'answer'` и `kind: 'reasoning'`
- KiloAgentBackend в `backends/kilo-agent-backend.mjs` уже имеет конструктор, но не имеет параметра streamMode

## Необходимые изменения

### 1. Backend (server.js)
1.1. Добавить переменную в .env
```bash
# .env
KILO_STREAM_MODE=native  # Варианты: native | buffered
```

1.2. Прочитать переменную при старте сервера
Место: после строки `console.log('✅ .env loaded')` (~строка 50)

log.info('stream-mode', STREAM_MODE);

1.5. Модифицировать событие `.onDone()`
Найти: блок `.onDone((sid) => ...)` (~строка 1400-1500)

```javascript
.onDone((sid) => {
  if (sid) newKiloId = sid;
  
  // ✅ ДОБАВИТЬ: в режиме buffered отправить всё единым блоком
  if (STREAM_MODE === 'buffered') {
    // Сначала reasoning (если есть)
    if (fullReasoningText) {
      ws.send(JSON.stringify({
        type: 'ai_chunk',
        sessionId,
        payload: { kind: 'reasoning', text: fullReasoningText, timestamp: Date.now() },
        buffered: true,  // ← Флаг для фронтенда
        ...(tabId ? { tabId } : {})
      }));
    }
    
    // Потом answer (если есть)
    if (fullText) {
      ws.send(JSON.stringify({
        type: 'ai_chunk',
        sessionId,
        payload: { kind: 'answer', text: fullText, timestamp: Date.now() },
        buffered: true,  // ← Флаг для фронтенда
        ...(tabId ? { tabId } : {})
      }));
    }
  }
  
  // Остальная логика без изменений...
  if (!resultData) {
    resultData = { subtype: 'success', sessionId: sid };
  }
  finish(newKiloId);
})
```
