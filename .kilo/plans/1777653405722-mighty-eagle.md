# План анализа структуры проекта Claude Code Studio

## Цель
Проанализировать структуру проекта, определить назначение основных файлов и директорий, и предоставить подробное объяснение пользователю.

## Шаги анализа

### 1. Исследование корневой директории
- Использовать glob для получения полного списка файлов и директорий в корне проекта
- Определить основные категории файлов (конфигурационные, исходный код, документация и т.д.)

### 2. Чтение ключевых конфигурационных файлов
- Прочитать package.json для понимания зависимостей, скриптов и мета-информации проекта
- Прочитать README.md (если существует) для общего описания проекта
- Прочитать tsconfig.json, .eslintrc или другие конфигурационные файлы

### 3. Анализ структуры исходного кода
- Исследовать директорию src/ для понимания архитектуры приложения
- Определить тип проекта (frontend, backend, fullstack) на основе структуры файлов
- Анализировать ключевые компоненты и модули

### 4. Исследование конфигураций Kilo
- Прочитать файлы в .kilo/ директории (.kilo/command/*.md, .kilo/agent/*.md, kilo.json)
- Понять, как проект интегрируется с Kilo CLI

### 5. Глубокий анализ с использованием explore агента
- Запустить explore агента для комплексного анализа кодовой базы
- Определить паттерны, фреймворки и архитектурные решения

### 6. Составление объяснения
- Структурировать информацию по категориям (frontend, backend, конфигурации, утилиты)
- Объяснить назначение каждого типа файлов
- Предоставить карту проекта с описаниями

## Ожидаемый результат
Подробное объяснение структуры проекта на итальянском языке, с указанием назначения файлов и директорий.
