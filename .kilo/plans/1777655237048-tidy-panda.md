# План переименования проекта: Claude Code Studio → KiloCode Studio

## Обзор
Необходимо переименовать проект из "Claude Code Studio" в "KiloCode Studio". Это фундаментальное изменение, затрагивающее конфигурационные файлы, документацию, CLI и встроенные строки.

## Файлы для изменения

### 1. package.json
- `"name": "claude-code-studio"` → `"name": "kilocode-studio"`
- `"bin": { "claude-code-studio": ... }` → `"bin": { "kilocode-studio": ... }`
- `"claude-code"` в keywords оставить (это внешняя зависимость)
- URL репозитория НЕ МЕНЯТЬ (согласовано с пользователем)

### 2. bin/cli.js
- Строка 41: `console.log(\`🚀 Claude Code Chat v${pkg.version}\`)` → `console.log(\`🚀 KiloCode Studio v${pkg.version}\`)`

### 3. server.js
- Строка 5785: `Source: Claude Code Studio` → `Source: KiloCode Studio`
- Строка 5796: `You are continuing work delegated from another AI agent (Claude Code Studio)` → `You are continuing work delegated from another AI agent (KiloCode Studio)`

### 4. telegram-bot.js
- Строка 1: Комментарий `// Telegram Bot Module for Claude Code Studio` → `// Telegram Bot Module for KiloCode Studio`

### 5. telegram-bot-i18n.js
- 9 упоминаний "Claude Code Studio" в строках переводов (строки 13, 33, 180, 331, 348, 483, 629, 646, 781)
- Замена на "KiloCode Studio" во всех языковых версиях (uk, en, ru)

### 6. README.md, README_RU.md, README_UA.md
- Все заголовки с "Claude Code Studio" → "KiloCode Studio"
- Ссылки на GitHub репозиторий НЕ МЕНЯТЬ (согласовано с пользователем)
- Ссылки на Notion статьи оставить как есть

### 7. scripts/release.js
- Текст в консоли (строка 100) - заменить упоминание проекта

### 8. install/README.md
- Текстовые упоминания "Claude Code Studio" → "KiloCode Studio" (строки 1-3, 61)
- GitHub ссылки НЕ МЕНЯТЬ

### 9. data/projects.json
- `"name": "claude-code-studio"` → `"name": "kilocode-studio"` (это демонстрационный проект)

### 10. package-lock.json
- Будет обновлён автоматически после изменения package.json

## Порядок выполнения

1. Обновить package.json (name, bin)
2. Обновить bin/cli.js (строка вывода)
3. Обновить server.js (строки 5785, 5796)
4. Обновить telegram-bot.js (комментарий)
5. Обновить telegram-bot-i18n.js (все строки переводов)
6. Обновить README файлы (только текст, не ссылки)
7. Обновить scripts/release.js
8. Обновить install/README.md (только текст)
9. Обновить data/projects.json
10. Запустить `npm install` для обновления package-lock.json
