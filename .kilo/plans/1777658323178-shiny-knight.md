## НАЙДЕНА ПРОБЛЕМА!

### buildUserContent (server.js: 1617-1621)
```javascript
function buildUserContent(text, attachments = []) {
  if (!attachments || attachments.length === 0) return text;  // возвращает СТРОКУ
  const blocks = buildAttachmentContentBlocks(attachments);   // возвращает массив
  if (text) blocks.push({ type: 'text', text });
  return blocks;
}
```

**Результат:**
- **БЕЗ attachments** → возвращает строку (text)
- **С attachments** → возвращает массив блоков

### runCliSingle (line 2296)
```javascript
let currentContentBlocks = Array.isArray(userContent) ? userContent : null;
```

**Логика ошибочна:**
- Если userContent СТРОКА (когда нет attachments) → currentContentBlocks = null
- Но строка И string.length существует! Позже в кода происходит проверка на `.length`

### KiloCLI.send (line 210-241)
```javascript
if (contentBlocks && contentBlocks.length) {
  const filePaths = [];
  const textParts = [];
  for (const block of contentBlocks) {  // ← contentBlocks может быть СТРОКОЙ!
    if ((block.type === 'image' || block.type === 'file') && block.source?.data) {
      // process files
    } else if (block.type === 'text' && block.text && block.text !== prompt) {
      textParts.push(block.text);
    }
  }
}
```

**ОШИБКА:**
Если contentBlocks это СТРОКА (а не массив), то `for (const block of contentBlocks)` итерирует по СИМВОЛАМ строки, а не по объектам блоков!

Result выглядит как:
```javascript
for (const block of "Hello world") {
  block === 'H'  // первая итерация
  block === 'e'  // вторая
  block.type    // undefined
  block.source  // undefined
}
```

### ФИНАЛ
Текст теряется потому, что:
1. На клиенте НЕ ОТПРАВЛЯЮТСЯ attachments (только текст)
2. buildUserContent возвращает СТРОКУ (не массив)
3. runCliSingle получает строку, но строго проверяет Array.isArray() → становится NULL
4. КСП KiloCLI.send получает NULL вместо contentBlocks → ничего не обрабатывается
5. finalPrompt теряет текст

### Решение
**Исправить buildUserContent чтобы всегда возвращать массив блоков:**

1. **Изменить buildUserContent (server.js: 1617-1621)**
   ```javascript
   function buildUserContent(text, attachments = []) {
     const blocks = [];
     // Сначала добавить вложения
     if (attachments && attachments.length > 0) {
       blocks.push(...buildAttachmentContentBlocks(attachments));
     }
     // Всегда добавить текст в конце (даже если пустой)
     blocks.push({ type: 'text', text: text || '' });
     return blocks;
   }
   ```

2. **Обновить комментарий**
   ```
   // Build Claude content blocks from text + file attachments.
   // Always returns ContentBlock[] array (never plain string).
   ```

3. **runCliSingle можно оставить без изменений**
   - Он правильно обрабатывает массив
   - currentContentBlocks = userContent (массив)

4. **KiloCLI.send будет работать корректно**
   - contentBlocks всегда массив
   - Обработка вложений и текста работает правильно
