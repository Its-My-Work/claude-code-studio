# План изменения вкладки настроек для отображения локального kilo.jsonc

## Обзор задачи
Добавить отдельную вкладку "kilo.jsonc (проект)" в настройках для отображения локального файла `.kilo/kilo.jsonc`. Это позволит пользователям редактировать проектный конфиг Kilo через интерфейс, сохранив существующую вкладку GLOBAL_RULES.md для глобальных правил.

## Анализ текущей структуры вкладок
- `config.json` - конфиг приложения
- `.config/kilo/kilo.jsonc` - глобальный конфиг Kilo
- `.env` - переменные окружения
- `GLOBAL_RULES.md` - глобальные правила (сейчас)
- `local-claude-md` - CLAUDE.md проекта (динамически)

## Требуемое изменение
Добавить новую вкладку `local-kilo-jsonc` с лейблом `kilo.jsonc (проект)` для отображения локального `.kilo/kilo.jsonc`

## План добавления вкладки для локального kilo.jsonc

### Шаг 1: Добавление вкладки в CFG_TABS_BASE
- Добавить новую вкладку `'local-kilo-jsonc', label: 'kilo.jsonc (проект)'` в CFG_TABS_BASE
- Оставить существующую вкладку `'global-rules-md', label: 'GLOBAL_RULES.md'` без изменений

### Шаг 2: Изменение логики загрузки
- В `openCfgEditor()` добавить загрузку локального `.kilo/kilo.jsonc` для новой вкладки
- Использовать путь `curWorkdir + '/.kilo/kilo.jsonc'` для локального конфига
- Добавить новый fetch запрос для получения содержимого локального файла

### Шаг 3: Изменение логики сохранения
- В `saveCfg()` добавить обработку `local-kilo-jsonc` вкладки
- Отправлять PUT запрос к `/api/config-files` с путем к локальному файлу
- Обновить логику чтения/записи локального kilo.jsonc

### Шаг 4: Обновление отображения пути
- В `updateCfgPathInfo()` добавить обработку `local-kilo-jsonc`
- Показывать правильный путь к локальному файлу `.kilo/kilo.jsonc`

### Шаг 5: Обновление логики чекбокса
- Переместить чекбокс "Использовать глобальные правила" только на вкладку `local-kilo-jsonc`
- Убрать чекбокс с вкладки `global-rules-md`

### Шаг 6: Тестирование
- Проверить что новая вкладка показывает локальный .kilo/kilo.jsonc
- Проверить сохранение изменений в правильный файл
- Убедиться что чекбокс работает только на вкладке проекта
- Проверить совместимость с существующими вкладками
