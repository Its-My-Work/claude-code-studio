# План исправления ошибок 404 в редакторе конфигурации

## Анализ проблемы
Ошибки возникают в функции `openCfgEditor` в файле `public/index.html`. Фронтенд пытается выполнить запрос к эндпоинту `/api/claude-md`, но этот эндпоинт не реализован в `server.js`, что приводит к ошибкам 404 и сбоям парсинга JSON, когда сервер возвращает HTML вместо JSON.

## Коренная причина
- Функция `openCfgEditor` выполняет параллельные запросы к 5 API эндпоинтам
- Один из них - `/api/claude-md` (строки 10115-10120 в index.html)
- Ответ парсится как JSON (строка 10126), но поскольку это 404, возвращается HTML, вызывая ошибку "Unexpected token '<'"
- Полученные данные (`cm`) нигде не используются в функции - они не присваиваются к `cfgFiles` как другие запросы
- Это похоже на остаточный код от запланированной, но не реализованной функции

## Варианты решения

### Вариант 1: Удалить проблемный запрос (Рекомендуется)
Удалить запрос к `/api/claude-md` из `Promise.all` в `openCfgEditor`, поскольку данные не используются.

**Необходимые изменения:**
1. Удалить объявление переменной `mdUrl` (строка 10115)
2. Удалить `fetch(mdUrl, { credentials: 'include' })` из массива Promise.all (строка 10120)
3. Удалить строку `const cm = await r2.json();` (строка 10126)
4. Изменить деструктуризацию с `[r1, r2, r3, r4, r5]` на `[r1, r3, r4, r5]` (строка 10118)

### Вариант 2: Реализовать недостающий эндпоинт
Добавить эндпоинты GET и POST `/api/claude-md` в `server.js`, следуя тому же шаблону, что и `/api/project-rules-md`.

**Необходимые изменения:**
1. Добавить эндпоинт GET `/api/claude-md` для чтения/записи файла `CLAUDE.md`
2. Добавить эндпоинт POST `/api/claude-md` для сохранения файла
3. Добавить вкладку 'claude-md' в `CFG_TABS_BASE`, если она должна быть редактируемой в редакторе конфигурации

## Рекомендация
Выбрать вариант 1 (удалить запрос), поскольку данные не используются и это выглядит как незавершенный код. Это немедленно исправит ошибки без добавления ненужной сложности.

## Шаги реализации
1. Изменить `public/index.html` для удаления неиспользуемого запроса к `/api/claude-md`
2. Протестировать, что редактор конфигурации открывается без ошибок
3. Проверить, что все остальные вкладки конфигурации по-прежнему работают корректно

## Проверка
После изменений:
- Редактор конфигурации должен открываться без ошибок в консоли
- Все существующие вкладки (config.json, глобальные правила, проектные правила и т.д.) должны оставаться редактируемыми
- В консоли браузера не должно быть ошибок 404
