# Анализ очистки проекта: неиспользуемые файлы и код

## Итог
Анализ проекта Claude Code Studio для выявления неиспользуемых файлов и мёртвого кода.

## Файлы для удаления

### 1. Неиспользуемые модули бэкенда
**Путь:** `backends/kilo-backend/kilo-runner.js`
**Путь:** `backends/kilo-backend/kilo-config.js` 
**Путь:** `backends/kilo-backend/kilo-response-parser.js`

**Статус:** НЕ ИСПОЛЬЗУЕТСЯ
- `kilo-backend.js` использует класс `KiloCLI` напрямую из `../kilo-cli.js`
- Эти файлы не импортируются нигде в кодовой базе
- Это выглядит как остаточные файлы от планируемой абстракции бэкенда, которую так и не была полностью реализована
- Эндпоинт `/api/local-kilo-config` в server.js предназначен для редактирования конфигурационных файлов `.kilo/kilo.jsonc` (другой назначение)
- `BackendFactory` уже использует `KiloBackend`, который оборачивает `KiloCLI`

**Рекомендация:** Удалить эти 3 файла

### 2. Неиспользуемый Tunnel Manager
**Путь:** `tunnel-manager.js`

**Статус:** НЕ ИСПОЛЬЗУЕТСЯ
- Не импортируется в `server.js` и ни в одном другом основном файле
- Упоминается только в `readme3.md` (документе безопасности)
- Возможно, предназначался для публичного доступа к серверу, но так и не был интегрирован

**Рекомендация:** Удалить или перенести в отдельный опциональный модуль

### 3. Планning/Исследовательские директории
**Путь:** `.planning/` (вся директория)

**Статус:** НЕ ИСПОЛЬЗУЕТСЯ В ПРОДАКШЕНЕ
- Содержит планы, исследования, заметки
- Не используется ни в одном production-коде
- Может быть полезен для исторической справки, но не требуется для работы

**Рекомендация:** Оставить или архивировать, но не нужно в продакшене

### 4. Дублирующиеся файлы README
**Путь:** `readme3.md`, `README_UA.md`, `PROJECT_RULES.md`, `rules.md`

**Статус:** НЕЯСНОЕ НАЗНАЧЕНИЕ
- `readme3.md` выглядит как анализ безопасности (украинский)
- `README_UA.md` это украинская локализация README
- `PROJECT_RULES.md` и `rules.md` - неясное назначение
- Основной `README.md` на английском

**Рекомендация:** Пересмотреть и, возможно, объединить

### 5. Директория скриншотов
**Путь:** `screenshots/` и `public/screenshots/`

**Статус:** НЕ ИСПОЛЬЗУЕТСЯ В КОДЕ
- Нет ссылок ни в одном HTML/JS файле
- Возможно, это активы документации, но не подаются

**Рекомендация:** Удалить или перенести в документацию

## Анализ кода

### Мёртвый код в server.js
1. **TELEGRAM_PROXY** - класс `TelegramProxy` определён, но не используется (строки 1015-1025)
2. **SSH-код** - `kilo-ssh.js` импортирован, но функционал SSH выглядит незавершённым
3. **MCP эндпоинты** - некоторые MCP эндпоинты могут иметь неиспользуемые обработчики

### Несуществующие импорты
- `backends/backend-factory.js` импортирован, но `BackendFactory.createBackend()` всегда возвращает `KiloBackend`
- Паттерн фабрики предполагает поддержку нескольких бэкендов, но реализован только Kilo
