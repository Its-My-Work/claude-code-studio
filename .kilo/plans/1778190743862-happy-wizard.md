# План тестирования отправки сообщений в чат через Playwright MCP

## Цель
Проверить, отправляются ли сообщения в kilo server при создании второй вкладки чата в Claude Code Studio, и если нет - выяснить причину.

## Шаги выполнения

### 1. Подготовка окружения
- Убедиться, что сервер Claude Code Studio запущен на localhost:3000 (запустить `npm start` если необходимо)
- Убедиться, что kilo server запущен на localhost:4098 (или другом порту из настроек)
- Установить Playwright браузер если необходимо (`playwright install`)

### 2. Открытие проекта в браузере
- Запустить браузер через Playwright
- Перейти на http://localhost:3000
- Сделать снимок страницы для анализа UI (`playwright_browser_snapshot`)
- Если требуется открыть проект: найти и кликнуть соответствующую кнопку/ссылку

### 3. Отправка первого сообщения
- Найти поле ввода сообщения в чате (textarea или input с id/class содержащим "message", "chat", "input")
- Ввести тестовое сообщение (например: "Hello, this is test message 1")
- Найти и кликнуть кнопку отправки (button с текстом "Send", "Отправить" или иконкой)
- Дождаться ответа от сервера (ожидать появления ответа в чате)

### 4. Создание второй вкладки чата
- Найти кнопку создания новой вкладки ("+" или "New Chat" или "Новая сессия")
- Кликнуть для создания второй вкладки чата
- Переключиться на новую вкладку (если требуется кликнуть на таб)

### 5. Отправка второго сообщения
- В новой вкладке найти поле ввода сообщения
- Ввести второе тестовое сообщение (например: "Hello, this is test message 2 from second tab")
- Отправить сообщение
- Дождаться ответа или хотя бы попытки отправки

### 6. Ожидание и анализ логов
- Подождать 30 секунд для обработки
- Прочитать логи сервера из директории `logs/` (файлы `*_server.log`)
- Найти записи о POST запросах к `/session/*/prompt_async` или аналогичным endpoint'ам kilo server
- Проанализировать:
  - Было ли отправлено первое сообщение (должно быть)
  - Было ли отправлено второе сообщение
  - Если второе не отправлено: проверить логи на ошибки, отсутствие сессии, проблемы с подключением

### 7. Проверка логов kilo server
- Если возможно, проверить логи kilo server на получение запросов
- Сравнить количество отправленных запросов с количеством полученных

## Ожидаемые результаты
- Первое сообщение должно быть успешно отправлено и обработано
- Второе сообщение должно также отправиться в kilo server
- Если второе сообщение не отправлено: определить причину (ошибка создания сессии, проблема с UI, баг в коде)

## Инструменты для анализа
- Playwright для автоматизации браузера
- Чтение файлов логов сервера
- Поиск в логах по ключевым словам: "prompt_async", "POST", "session", "error"

## Риски и обработка ошибок
- Если UI изменился: использовать snapshot для анализа актуального интерфейса
- Если порты отличаются: проверить конфигурацию в .env или коде
- Если kilo server недоступен: проверить его статус через health endpoint
