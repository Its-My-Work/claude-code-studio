## Цель
Изменить порядок вкладок в модальном окне настроек (Настройки) и обеспечить отображение пути и расположения файла для каждой вкладки.

2. Глобальный kilo.jsonc (.config/kilo/kilo.jsonc)

## Необходимые изменения

### 1. Изменение порядка в CFG_TABS_BASE
Файл: `public/index.html` (строка ~10100)

Изменить массив `CFG_TABS_BASE` для соответствия новому порядку:

### 2. Обновление функции updateCfgPathInfo
Файл: `public/index.html` (строка ~10215)

Дополнить функцию `updateCfgPathInfo` для отображения путей ко всем файлам:

```javascript
function updateCfgPathInfo(id) {
  const el = $i('cfgPathInfo');
  if (!el) return;
  let path = '';
  if (id === '.env') {
    path = '.env';
  } else if (id === 'config.json') {
    path = 'data/config.json';
  } else if (id === '.config/kilo/kilo.jsonc') {
    path = '~/.config/kilo/kilo.jsonc';
  } else if (id === 'global-rules-md') {
    path = cfgFiles['__globalRulesPath'] || '~/.config/kilo/GLOBAL_RULES.md';
  } else if (id === 'local-kilo-jsonc') {
    path = cfgFiles['__localKiloPath'] || (curWorkdir ? `${curWorkdir}/.kilo/kilo.jsonc` : '.kilo/kilo.jsonc');
  } else if (id === 'project-rules-md') {
    path = cfgFiles['__projectRulesPath'] || (curWorkdir ? `${curWorkdir}/PROJECT_RULES.md` : 'PROJECT_RULES.md');
  }
  if (path) {
    el.textContent = path;
    el.classList.remove('hidden');
  } else {
    el.textContent = '';
    el.classList.add('hidden');
  }
}
```

### 3. Проверка корректности путей
Убедиться, что переменные `APP_DIR` и `curWorkdir` доступны в клиентском коде. Если необходимо, передать их с сервера.
