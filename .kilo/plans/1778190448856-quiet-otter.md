# План: Изменение отображения Session ID в интерфейсе

## Цель
Изменить блок `<span id="sessBarSessionId">` так, чтобы он отображал `kilo_session_id` из базы данных, если он существует, иначе скрывать блок полностью. Вместо отображения временного `currentSessionId`.

## Текущее поведение
- В `updateSessBar()` блок `sessBarSessionId` всегда отображает `currentSessionId` (временный ID сессии).
- Аналогично в других местах кода.

## Предлагаемые изменения
1. В функции `updateSessBar()` (около строки 7510-7514):
   - Проверить наличие `sess.kilo_session_id`.
   - Если есть: установить `sessIdEl.textContent = sess.kilo_session_id` и `sessIdEl.style.display = ''`.
   - Если нет: `sessIdEl.style.display = 'none'`.

2. В функции обработки события 'session_id' (около строки 5848-5852):
   - Аналогично изменить логику: использовать `d.kilo_session_id` вместо `d.sessionId`, и скрывать если нет.

3. В функции `updateSessBarSkills()` (около строки 7894-7896):
   - Аналогично: использовать `sess.kilo_session_id` если доступно.

## Проверка
- Проверить, что `kilo_session_id` возвращается в ответе `/api/sessions/${sessionId}` (уже есть в базе данных).
- Убедиться, что в Kilo режиме `kilo_session_id` устанавливается правильно (уже реализовано на сервере).

## Тестирование
- В режиме Kilo: сессия должна отображать Kilo session ID.
- В режиме Claude: блок должен быть скрыт (поскольку `kilo_session_id` не устанавливается).
- При отсутствии Kilo session ID: блок скрыт.</content>
